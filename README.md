# Umesh & Neethu — Wedding Invitation

A cinematic, mobile-first digital wedding invitation, built from the reference
invitation video: ivory paper, antique gold foil, brass lamps, lotus, and the
Kerala heritage roofline.

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # production build
```

## Changing the wedding details

Everything lives in **`src/config/wedding.ts`** — names, parents, date, time,
venue, maps link, WhatsApp number, gallery list. No component hardcodes any of
it, so a non-developer can edit that one file safely.

Wording (both languages) lives in **`src/config/content.ts`**.

## Photographs

Drop files into `public/images/` using the names in `wedding.ts`
(`couple/groom.jpg`, `gallery/moment-01.jpg`, …). Until a file exists the page
shows an ornamental frame in its place, so it never looks broken. See
`public/images/README.txt`.

## Music

Add `public/music/wedding.mp3`. It never autoplays — it starts only when the
guest taps "Open Invitation", and the floating control mutes it. The mute
choice is remembered for the session.

## RSVP

Set `contact.whatsapp` in `wedding.ts` (digits with country code, e.g.
`919876543210`). The RSVP composes a WhatsApp message — there is no backend and
no database. Left blank, the section explains how to switch it on.

## The scenes

`OpeningScene` (envelope) → `HeroScene` (arch) → `InvitationReveal` (card) →
`CoupleIntro` → `StorySection` → `FamilySection` → `PhotoMemories` →
`WeddingDetails` + `Countdown` → `VenueSection` → `RSVPSection` →
`FinalInvitation`.

## Notes

- Share image is generated by `src/app/opengraph-image.tsx`, so it always
  matches the names and date in the config.
- Every animation is disabled under `prefers-reduced-motion`.
- Ornaments are inline SVG — nothing extra to download, sharp at any density.
